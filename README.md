# 🧮 Calculadora Simples em Python

## 📌 Descrição
Uma calculadora simples feita em Python que realiza operações básicas.

Projeto criado para praticar lógica de programação.

## ⚙️ Funcionalidades
- Soma (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)

## ▶️ Como usar
1. Execute o arquivo em Python
2. Digite dois números
3. Escolha a operação desejada
4. Veja o resultado no terminal

## 🧠 O que aprendi
- Entrada de dados com input()
- Uso de if e elif
- Operações matemáticas básicas
